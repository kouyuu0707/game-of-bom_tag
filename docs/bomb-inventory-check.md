# 爆弾の所持・補充の動作確認

Unity 6000.3.10f1 で Assets/GameScene.unity を開いて再生します。
補充用の緑色の球4個と画面左上の残弾表示は再生時に生成されます。
配置は GameManager の BombSupplySetup の Pickup Positions で変更できます。

1. 開始時に `Bombs: 2/5` と表示される。
2. Bを2回押すと爆弾が2個置かれ、残弾が0になる。もう一度押しても増えない。
3. Eを押すと2個とも消える。残弾は0のまま。空の状態でEを押してもエラーにならない。
4. 緑色の球に触れると球が1個消え、所持数が1増える。鬼が触れても消えない。
5. Retryで再開すると2個所持に戻り、補充アイテムも復活する。
6. 再開後、3個拾うと5/5になる。4個目に触れても消えず、5を超えない。
7. その球のそばでBを押して空きを作ると、補充できる。
8. 設置・補充を繰り返してからEを押すと、自分の設置済み爆弾が全部消える。
9. 鬼に捕まると移動・設置・起爆・補充が止まり、Retryできる。
10. Consoleに新しいエラーが出ていないことを確認する。

この変更はローカル用です。オンラインの所有者管理・同期、爆風、ダメージは未実装です。
一斉起爆はプレイヤーごとのBombInventoryに記録された爆弾だけを対象にします。
