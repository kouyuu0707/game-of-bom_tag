# シングルモード

マップは開始ごとに自動生成します。[配置・Retry・New mapの手順](procedural-map.md)も確認してください。

協力モードと同じOnlineTestシーン・同じゲーム処理で、1人で遊べます。
Unity Cloud連携、参加コード、2つ目のアプリは不要です。
シングル専用の通信層はソケットや待受ポートを開かず、外部のプレイヤーも受け付けません。

## 起動手順

1. Editorの再生と起動中のexeを終了し、`feature/bomb-inventory` をPullします。
2. Unityのコンパイル完了後、`Tools → Bomb Tag → Create or Open Online Test` を選びます。
3. Editorで▶を押し、メニューの **Single Player** を押します。
4. 1人ですぐにゲームが始まります。Start gameやLocal Hostを押す必要はありません。
5. exeで遊ぶ場合は `Build Windows Connection Test` で作り直し、そのexeからSingle Playerを選びます。

## ルール

- HP3、爆弾2個で開始します。所持数は最大5個です。
- WASDか矢印で移動、Bで設置、Eで自分の爆弾を一斉起爆します。
- 鬼2体が追跡し、爆風1回で倒せます。爆風は自分にも当たります。
- 緑色の補充アイテム8個を拾うと1個補充します。所持数5個なら残ります。
- 被弾後1秒間は無敵です。HP0でGame Over、鬼全滅でGame Clear!です。
- RetryでHP・爆弾・鬼・補充アイテム・位置をリセットし、1人で再開できます。
- Back to menuで終了して、シングルをやり直したり協力モードを選んだりできます。
- 鬼と同時に自分も倒れた場合はGame Overです。

## 確認する項目

- Unity Cloud未連携・インターネット未接続でもSingle Playerから開始できる。
- 1つのEditorまたはexeだけで、移動・設置・起爆・補充・被弾・勝敗が動く。
- Retryが1人で押せ、全アイテムとHP・残弾が初期状態へ戻る。
- Back to menuからもう一度Single Playerを選んでも以前の鬼・爆弾・アイテムが残らない。
- メニューへ戻ってLocal Hostを選ぶと2人待機になり、1人ではStart gameを押せない。
- Local Joinで2人接続すると従来どおり開始・リトライできる。
- 協力モードを終了してシングルへ戻っても1人で開始できる。
- 古いexeは使わず、協力モードの両方のアプリを最新版へ更新する。

所持数・HP・取得・勝敗・モードのルールを確認する32件のテストを.NETで実行し、全件成功しています。
Unity依存の通信層テストと、Unityでのコンパイル・再生・モード切り替えはクラウドでは未検証です。
UnityのTest Runnerからは全43件（通信層2件・壁の判定3件を含む）を実行できます。
